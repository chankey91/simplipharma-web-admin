SimpliPharma Admin

GST workspace — CA how-to guide

For the chartered accountant / tax team preparing GSTR-1, GSTR-3B, ITC, and e-invoice JSON.

This app does not file the return. It classifies books and downloads offline GSTN JSON. You upload and file on gst.gov.in. Issued invoice numbers and tax rupees are never rewritten. It does not generate an IRN, pull GSTR-2B live, or store GSTN passwords.

3. One-time: company GST settings

Open Settings (top right of the GST bar). Fill legal name, trade name, 15-character GSTIN, address, state + state code, pincode, phone, email, drug licence.

  • Filing frequency: Monthly or QRMP. QRMP only sets filing_typ: Q on the JSON; you still pick a month for the books.
  • E-invoice (IRN) required: Turn on only if turnover requires IRN. Enables IRP JSON download. Does not call NIC.

Click Save settings. Format is checked (15 characters). There is no GSTN check-digit or portal lookup.

4.1 Cards

  • This month — invoiced orders — invoices vs snapshots.
  • Master-data exceptions — invalid store/vendor GSTIN; medicines with no HSN (code).

Fix GSTINs before backfill when you can. Backfill uses the GSTIN at the time you run it. Changing a GSTIN later does not rewrite old snapshots.

4.3 Backfill (historical invoices)

  1. Click Process this period or Preview & backfill.
  2. Read the preview (counts + sample CGST/SGST split).
  3. Confirm. Only a gst snapshot is written. Invoice numbers and tax rupees stay as billed.

Backfill is faithful to the issued bill: existing tax split as intra-state CGST + SGST (place of supply = company state). It does not re-rate mixed 5%/12% lines on old invoices. New fulfilments and notes store line-level HSN, rate, taxable, tax (one GSTR-1 item per rate). Locked periods must be reopened before backfill.

5. GSTR-1 — outward supplies JSON

You will see B2B / B2CL / B2CS / CDNR / CDNUR / HSN counts, GSTIN, fp, SHA-256 hash, file size, warnings, and an invoice register (number, date, type, party, rates, taxable, tax, total — first 400 rows).

TypeMeaning in this app
B2BBuyer GSTIN is a valid 15 characters
B2CLUnregistered, inter-state, invoice value ≥ ₹1 lakh (from August 2024)
B2CSOther B2C (including small inter-state)
CDNRCredit / debit note to a registered buyer
CDNURCredit / debit note to unregistered

JSON version GST3.2.1. Document numbers cleaned to GSTN-safe characters (max 16). Mixed-rate invoices emit one item per rate. Files over 5 MB are rejected.

Download and upload

  1. If the register is empty or snapshots are missing → Overview and backfill.
  2. Click Download GSTR-1 JSON.
  3. Confirm Lock this period when asked (stores filename, SHA-256 hash, fingerprints for amendments).
  4. On gst.gov.in: Returns → GSTR-1 → Prepare Offline → upload returns_MMYYYY_GSTR1_<GSTIN>.json → validate in the GSTN offline tool → file.
  5. In the app: Mark GSTR-1 filed and paste the ARN.

After lock, Download amendment JSON emits B2BA / CDNRA only for invoices whose fingerprint changed. B2CS cannot go in amendment tables here.

6. Period lock

openBackfill and dated writes allowed
gstr1 readyLocked after GSTR-1 download
gstr1 filedARN saved after portal file
gstr3b filedMonth closed for GST

While status is not open you cannot fulfil a sales order, or create a credit note, debit note, purchase invoice, or purchase return, dated in that month, and you cannot backfill. Reopen only if you will regenerate JSON and re-upload if already filed.

7. ITC / GSTR-2B

The app cannot pull 2B from GSTN. Download GSTR-2B JSON from the portal, then click Upload GSTR-2B JSON.

StatusMeaning
matchedSame vendor GSTIN + invoice number; taxable/tax within ₹1
amount mismatchFound on both sides, figures differ
books onlyIn SimpliPharma, not in uploaded 2B (or vendor GSTIN missing)
portal onlyIn 2B, not in this month’s purchase books

Eligible ITC is from inward snapshots with a valid vendor GSTIN; purchase returns reverse ITC. Use Download ITC Excel for working papers. ITC is not auto-claimed on the portal.

  1. Review 3.1 vs GSTR-1 and 2B workings.
  2. Download GSTR-3B JSON.
  3. gst.gov.in → Returns → GSTR-3B. Confirm 3.1 and ITC.
  4. Mark GSTR-3B filed and save ARN.

9. E-invoice (IRP JSON)

Only if E-invoice (IRN) required is on in Settings. Downloads IRP JSON version 1.1 for B2B invoices with a snapshot. Upload in the NIC / e-invoice bulk / taxpayer tool. The app does not generate an IRN, call NIC, or create e-way bills. IRN is not written back onto the SimpliPharma invoice in this version.

13. What this screen will never do

  • File GSTR-1 or GSTR-3B by itself
  • Log in to GSTN or store portal passwords
  • Generate IRN or e-way bill numbers
  • Recalculate or change a bill already sent to the retailer
  • Fill 3B reverse charge, imports, or ISD from operations data
  • Prove a GSTIN with the official check digit or GSTN search
